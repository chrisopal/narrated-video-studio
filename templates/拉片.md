# 拉片：从参考片学结构

用户给一条参考视频（“做成这种感觉”），或者要进入一个新题材时，先拉片，再写稿。原片只用来分析，不进成片。

1. 机器先量：`python3 ../kit/build.py study 参考片.mp4`。得到 `study/<名字>/shots.json`（每个镜头的起止和时长）、节奏数据（平均镜头时长、每分钟切点数、第一刀在第几秒）和联系表。溶接多、暗场多的片子把阈值调低：`study 参考片.mp4 0.15`。
2. 看联系表填镜头表，只写看得见的：
   - size 景别：远 / 全 / 中 / 近 / 特
   - category：定场 / 主体 / 访谈 / 反应 / 插入 / 字卡 / 图表 / 资料
   - camera：固定 / 推 / 拉 / 摇 / 移 / 跟 / 手持
   - frame：画面里有什么；onscreen_text：屏上文字；audio：旁白、原声还是音乐
   - rhythm：钩子 / 铺垫 / 推进 / 转折 / 兑现 / 喘息 / 收束
   - note：一句话，观众此刻看到什么、为什么没划走
   起止和时长是量出来的，不要改。
3. 把“骨架”和“皮肤”分开：
   - 骨架可以学：叙事顺序、每段占比、镜头时长分布、钩子的做法、什么时候出数字、字幕形态、声音和画面切换的关系。
   - 皮肤必须换：配色、角色、标志性画面、标题样式、原话、音乐。
4. 写成方法卡，每条一句：规则 / 什么时候适用 / 什么时候别用。放进项目的 `study/方法.md`。
5. 写稿时每条方法记“采用 / 改造 / 不用”。它是参考不是配额；和这期的内容冲突时以内容为准。

结论分三级写：量出来的、看出来的、推测的。只有文字稿就不评价画面；没识别过的音乐不猜歌名。
