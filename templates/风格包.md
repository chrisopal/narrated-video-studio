# 风格包

风格包是一整套画法：一个主题（配色和背景）加几样招牌组件。在 `brief.json` 里写 `"packs":[…]` 加载；`scenes.js` 整份包在 `(() => { … })();` 里，开头用 `const {…} = PACK.包名;` 取要用的函数。
每个包都有一条能跑的小样片：`kit/gallery/<名字>/scenes.js`，照着改最快。

包有两种来源，维护方式不同：

- **从旧片收进来的**（ink、figures、map、litho、lacquer）：由 `legacy/tools/mkpacks.py` 生成，**不要手改** `kit/packs/` 里这五个文件；要改就改 `legacy/tools/glue/` 里的接合代码，再在仓库根目录运行 `python3 legacy/tools/mkpacks.py`。
- **从别的开源项目收进来的**（art）：上游源码原样放在 `legacy/huashu/`，由 `legacy/tools/mkart.py` 生成 `kit/packs/art.js`，**不要手改**生成的文件；要改就改 `legacy/tools/glue/art.js`，再运行 `python3 legacy/tools/mkart.py`。取了什么、没取什么、怎么跟上游更新见 `legacy/huashu/UPSTREAM.md`。
- **自己实现的**（glow、morph、whiteboard、collage、kinetic、iso、holo、ui、stick、host、engrave、woodcut、dossier、industry，以后新做的也一样）：直接维护 `kit/packs/<名字>.js`。新做一套照 `templates/新风格包任务书.md`。

自己实现的包，时间参数的习惯都是 `(t, t0, …)`：t 是全片时间，t0 是开始时刻；能“画出来”的组件大多返回画完的时刻，方便往下排。每个包的文件开头有完整的参数说明，下面只列招牌组件。封面 `art(c,…)` 给的是另一张画布：要在封面里用包组件，用包里的 `on(ctx, fn)`（发光包叫 `withCtx`）临时换画笔，带文字的组件不行（`ui` 包例外）。

## ink 水墨引擎

画法：先画在一张透明的“绢”上，再整张淡入淡出叠到宣纸底上。所有函数第一个参数是这张绢的画笔 `G`，时间用进场后的秒数 `u`。

- 分场 `layer(t, 起, 止, (G,u)=>{…}, {fi, fo})`；费时的东西只做一次 `once('名字', () => mountain({…}))`
- 山 `mountain({seed, base, amp, scale, peaks:[{x,h,w}], col:INK|TQ, alpha, fade, edge, fold, blur, dots, trees})` → `{c, ridge}`；墨色晕开 `revealDraw(G, 山.c, x, y, 进度, 种子)`；云雾 `mist(G, u, [{x,y,r,a,v,sy}])`；镜头 `cam(G, u, 时长, {z0,z1,x0,x1,y0,y1})`
- 竖排字，右起，逐字显影 `vtext(G, u, {t0, t1, cols:['第一列','第二列'], x, y, size, gap, lead, font:F.song|F.songb|F.brush|F.cao, color, rate, fd, wet})`；乌丝栏 `rules`；章题 `chapter(G, u, t0, '壹', '眉山', '景祐三年 · 一〇三七')`
- 印章 `makeSeal('东坡', 宽, 高, 种子)`（一、二、四个字）+ `sealStamp(G, u, 印, x, y, t0)`
- 点景：`drawWalker` `drawBoat` `drawGeese` `makeRipples/drawRipples` `rain` `makePlum/drawPlum` `makeBamboo/drawBamboo` `makeWillow/drawWillow` `makeClouds` `moon` `nightWash` `makeCliff` `drawWaves` `brushCurve` `makeStroke`
- 颜色：墨 `INK`、天青 `TQ`、朱 `SEAL`。通用组件（时间轴、引文卡等）在 `songink` 主题下可以直接用，会换成宋体。
- 字号规矩：正文竖排不小于 32；毛笔体、草书只有旧片用过的字（检查会报缺字）。
- 坐标约定：`vtext` 的 `x` 是第一列（最右一列）的中线，`y` 是字的顶端，往左每列隔 `gap`；`rate` 是相邻两字出现的间隔秒数，`fd` 是一个字显影用的秒数。`sealStamp` 的 `x,y` 是印的中心。`mountain` 画出来的图比画面宽（缺省 2320），惯例是画在 `x = -200 - u*速度` 让它慢慢横移，所以 `peaks` 的 `x` 可以写到 2150 左右。
- 片长 = 开头 0.9 秒 + 各句时长（无旁白段落就是 `dur`）+ 结尾 3 秒。取时用 `T('句id')`（这句开始）和 `N('句id')`（下一句开始）。

## figures 固定人物

- `scholar(G, x, 脚底y, 大小, u, {pose:'stand|walk|read|seat|seatBow|bow|toast', age:0..2, face:±1, wind, staff, alpha, pace})` 宋人文士（白袍、乌帽、竹杖）
- `official(G, x, 脚底y, 大小, u, {pose:'stand|walk|seat|bow|mourn', servant:true, face, wind, alpha})` 清末官员；`servant` 画随从
- 现在只有这两个男性人物，没有女性、孩童、僧道、武人。主角不是这两类时不要硬套。
- 新人物：照这两个的结构另写一个（头、袍、袖、步态分开画），先在本片里用，复盘时再决定是否收进来。同一个系列的主角用同一个人物，观众才认得。

## map 行迹地图

```js
const M = makeMap({ view:[96,16,126.5,42.5], title:'苏子行迹图', start:'眉山', main:['眉山','汴京','黄州'], places:{新地名:[经,纬]}, wall:false, tone:'ink' });
M.leg([{p:'眉山'}, {p:[105,31.5]}, {p:'汴京', lab:'汴京 · 一〇五七', side:-1}, {p:'儋州', sea:true}], ['出蜀赴京','兄弟同榜'], '一〇五六');
layer(t, a, b, (G,u) => M.draw(G, u, 时长, { leg:0, traveler, seal:true }));      // 一段行程：旧路变淡、朱线生长、小人沿线走、到了落地名
layer(t, a, b, (G,u) => M.draw(G, u, 时长, { intro:'眉山', cap:[…], year:'…' })); // 开场：从全图推到出生地
layer(t, a, b, (G,u) => M.draw(G, u, 时长, { all:true, cap:[…] }));               // 收尾：全部行程依次画出
```

- `view` 西、南、东、北；落在东经 94–130、北纬 12–46 以内用细海岸线，超出用全亚洲的粗海岸线。`tone:'litho'` 配石印画报，`wall:true` 画河西一段长城。
- 行程里没名字的点 `{p:[经,纬]}` 只用来让路线拐弯；`lab` 是路过这一站时落下的字（`地名 · 年份` 会分两列，垫纸条），`side:-1` 把字放到点的左边；终点不用写 `lab`，到达时自动落大字地名；`sea:true` 走水路，`arrest:true` 押解。
- `seal:true` 到达时在终点旁再盖一方地名印（只支持一、二、四个字的地名），和终点地名挨着，嫌挤就不要。`capX` 挪题记的横向位置（缺省 1790）。
- 自带地名（可直接写名字）：眉山 成都 长安 汴京 凤翔 杭州 密州 徐州 湖州 黄州 汝州 颍州 扬州 定州 惠州 儋州 雷州 廉州 虔州 金山 常州 广州 韶州 南雄 梅关 赣州 吉安 南昌 九江 桐城 郑州 洛阳 潼关 西安 乾州 泾州 平凉 兰州 平番 古浪 凉州 山丹 甘州 肃州 嘉峪关 玉门 安西 星星峡 哈密 古城 迪化 澳门。别的地名在 `places` 里补经纬度；写了不认识的名字会报错并说缺哪个。
- `traveler(G, x, y, {face, alpha, mode, t})` 自己画行者（文士、车、船）；不给就是斗笠小人。
- 地名的经纬度、古今对应、哪年到哪，都是断言，进 `facts.json`。

## litho 石印画报

画心在左，题签栏在右。水墨画面画完自动过一遍刻版（排线、轮廓），字不过刻版。

- `page(t, 起, 止, (G,u)=>{画面}, {text:(G,u)=>{题签}, fx:false 不刻版（地图）, first, last})`，相邻两页自动从右向左揭开
- 题签纸条：叙述 `narr(G,u,{t0,t1,cols,x,y})`、诗句 `poem`、大字 `say`
- `plate(t, {chapter:{glyph:'辩', place:'梅关 吉安', date:'…', t0}, count:{a:'第十九日', b:'行约九百里', p:进度0..1, marks:[…]}, title})` 版框和题签栏，放在所有 page 之后
- `counter(t, [[时刻, 日数, 里数], …])` 在关键时刻之间插值；`cn(1234)` → 一千二百三十四
- 山用 `mountainLined()`（带轮廓线和皴）；人物大小乘 `FIG`；道具 `drawCart` `drawCamels` `drawGunboat` `makeFort` `drawBigWillow` `sunDisc` `ground` `clouds` `snow` `paperSnow` `snowCap` `stars` `earthWall` `drawPeach` `tufts` `drawBags` `drawSheets` `drawDossier`

## lacquer 漆屏风

两条线并行：上栏大人物和大时代，下栏小人物。一切动作按旁白句子定时，所以这套风格必须有旁白（样片里用无旁白段落代替句子）。

- `screen(t, [{at:0, draw:G=>{…}}, {at:换屏时刻, draw:G=>{…}}], {side:{top:{badge:'帝', a:'孝文帝', b:'太和七年'}, bottom:{badge:'婢', a:'王钟儿', b:'四十五岁'}}, year:'公元 四八三 年', chapter:'叁 保母'})`，换屏时六扇依次翻转；字幕落在底栏
- 每屏里：`G.save(); clipReg(G,1); …上栏，地面 G1…; G.restore();` 下栏同理用 `clipReg(G,2)`、`groundLine(G,G2)`、地面 `G2`；压暗一栏 `veil(G, 栏, 程度)`
- 定时：`from('句id')` 这句开始后淡入；`upto('句id')` 结束后淡出；`vis('a3','a5')` 从 a3 显到 a5；`pr('句id')` 念到哪了；`mv(起, 止, 时刻, 时长)` 平移
- 人物 `wom / emp / kid(G, x, 地面, 大小, {f:脸, pal:PAL.xx, age, …}, 透明度)`，脸在 `FACE`、配色在 `PAL` 里加；标签 `tag(G, ['孝文帝'], x, y, 字号, 透明度)`
- 道具 `lqHill lqTree lqWall lqHall lqCanopy lqHorse lqCart lqTent lqPagoda lqStele lqBed lqWaves lqMound lqPot lqCloud(s) lqDisc lqFloor lqThrone lqLamp lqBanner lqFire lqArrows lqSoldier lqQue lqIncense lqBuddha lqHouse`
- 墓志 `lqStele` 的志题现在还是《王钟儿》那一方的字（收件箱里记着要放开）。

## glow 扁平发光世界

- `blob(t, x, y, r, {col, seed, wob, tip, hi, glow, idle, core, face:{look, smile}, t0, t1, a})`：发光圆润形体（外发光、暗面、亮面、高光），自带呼吸和漂浮；`tip` 拉出水滴尖，`face` 加眼睛嘴巴，`t0` 弹入、`t1` 退场
- `swarm(t, {x, y, rx, ry, n, r, cols, seed, k, energy, heat, hot, draw})`：成群的小单元各自漂；`energy` 越大抖得越快，`heat` 把颜色推向 `hot`
- `stream(t, 路线点, {n, r, col, speed, k})`：沿圆滑路线流动的一串发光小点（系统里“什么往哪儿走”）
- `zoomInto(t, z, [{draw(R,f,t), px, py, rho}, …], {x, y, R})`：对数缩放镜头，`z` 是连续层号，往回走就是拉出来
- `bubble(t, t0, '文字', x, y, {tail, t1})` 圆角标签气泡；`scaleBar(t, t0, z, ['杯子','水滴','微粒'], x, y, w)` 尺度条；`dot` 三层色块小圆；`PAL` 色板

## morph 概念形变

- `frame({x,y,w,h}, {xr, yr})` 坐标框，返回 `F.p(数据x, 数据y)` 换算；`axes(t, t0, F, {labels})` 轴从原点长出来
- `gridWarp(t, t0, dur, F, [a,b,c,d], {in, ghost})`：整张网格按线性变换慢慢变形，返回值可当新的 `F` 用，别的图形跟着变
- `drawOn(t, t0, dur, 点组, {col, dot})` 一条线“写”出来；`plot(t, t0, dur, fn, F)` 函数图像从左写到右
- `morphPath(t, t0, dur, 点组A, 点组B, {col, colB, close, fill})`：A 点对点变成 B（自动按弧长重采样）
- `dotOn` 点沿路径走；`label(t, t0, '字', px, py, lx, ly)` 带引线的短标签；`brace` 大括号；`formula(t, t0, ['宽', {s:'x', sup:'2'}], x, y, sz)` 一行简单式子
- 取点：`sample(fn, x0, x1, n)`、`steps(fn, x0, x1, n)`、`shape.line/rect/circle/ngon/stairs`、`resample`、`along`；色板 `C`
- 限制：形变只支持单条路径；式子只有一行、一层上下标

## whiteboard 白板手写

- `board(t, keys, fn, {w, h})`：白板镜头，`keys=[{t, x, y, z, d}]`，`fn(cam)` 里用白板坐标画；`fit(x0, y0, x1, y1)` 算出“整块放进画面”的拉远机位
- `write(t, t0, '文字', x, y, 字号, {col, rate})`：手写感文字逐字擦出（字体 KT，整串登记给检查）；`said('句id', '词', .5)` 返回这个词念出后半秒，给 `write` 当 t0
- `sketchLine / sketchArrow({via, dash}) / sketchBox / sketchCircle / sketchPath / underline({double})`：手画图形，略抖、不完全闭合
- `pen()` 笔尖（`board` 自动画）；`INK` 黑笔、`ACC` 强调色（换色用 `themePatch:{a1}`）
- 限制：字是楷体字形逐字擦出，不是真笔顺；镜头要手排，白板越大字号要越大

## collage 桌面拼贴

- `cam(t, keys, fn, {drift, push})`：桌面镜头平滑推移，`keys=[{t, x, y, z, d}]`
- `paper(t, t0, x, y, w, h, {rot, tape, pin, tear, kicker, title, lines, marks, rings, out})`：纸片/剪报卡一拍二落到桌上；`marks` 用荧光笔划某行第 a–b 个字，`rings` 用红圈圈字
- `photoCard(t, t0, x, y, w, h, {img, cap, rot})`：白边照片；没给 `img` 就画灰色斜纹占位并标“示意”
- `sticky(…)` 便签；`thread(t, t0, 点组)` 红线一段段长出来，拐点钉图钉；`spot(纸片参数…, u, v)` 求纸片上某点的桌面坐标给红线当端点
- `marker` 荧光笔、`ring` 红圈、`redArrow` 红箭头、`scrawl(t, t0, '批注', x, y)` 红笔手写批注、`strip(t, t0, '示意材料，非真实档案', x, y)` 黑底标签条；`q(t)` 一拍二的时间量化
- 规矩：没有真实材料不用这套做成片；画面上写明哪些是示意材料；镜头别扫过还没讲到的纸片（阅读时长会误报）

## kinetic 动态文字

- `screens(t, [{at, bg:'paper|black|accent|white', fn(pal,u), wipe}], {d})`：按时刻换屏，硬切或色块擦切；屏里的 `TH` 颜色临时换成这一屏的配色
- `slam(t, t0, '词', {x, y, sz, al, from:'scale|up|down|left|right', maxW, hit})`：0.15 秒砸到位、小过冲后完全静止，落地响一声
- `sub(t, t0, '辅句', {…})`：辅句，晚主词 0.2–0.3 秒，字号用 `RATIO`（3.4）换算
- `listUp(t, [{at, text}], {allOn})` 清单一条条砸上来，旧的退灰；`countBig(t, t0, 数字)` 巨大序号；`bar(t, t0, {x, y, w, from})` 强调色粗条擦出；`fit` 自动缩字（不小于 32）
- 限制：没有原生竖版排法；不能自动对准配乐拍点；一屏超过 5.5 秒要再排一拍内容

## iso 等距沙盘

- `stage(t, {x, y, z, s, sx, sy}, fn)`：设镜头（只能平移推拉，投影角固定）；`cam(a, b, k)` 两个镜头之间插值；`P(x, y, z)` 沙盘坐标转屏幕
- 实体函数不直接画，返回“件”，交给 `scene([…])` 按遮挡排好再画（自动加影子）：`ground`、`block(x, y, z, w, d, h, {col, t0})`、`house(…, {roof, open, lift, inside})`（`open` 从 0 到 1 时屋顶升起、前墙降下露出 `inside`）、`tree`、`crate`、`belt`、`truck(pos, {load})`
- `route(点组)` + `road(t, R)` 铺路 + `mover(t, R, [[时刻, 距离], …], pos=>件)` 沿路线走；`slot(pos, i)` 车斗位置
- `stack(t, t0, n, x, y, {cols, rows})` 小箱子一只只落下堆出数量；`tag(t, t0, '文字', x, y, z)` 立在沙盘上的标签（直接画，写在 `scene` 之后）
- 限制：路线只有直线拐角；一个件跨进好几个件里时要手动切段

## holo 全息界面

- `wire(t, t0, dur, paths, {dim, lit})`：一组线框依次描出；`dim` 退暗、`lit` 点亮
- `partFrame(t, t0, x, y, w, h, {label, idx})` 四角括号收拢框住部件；`leader(t, t0, [x1,y1], [x2,y2])` 引线
- `readout(t, t0, {label, value, unit, decimals, dur}, x, y)`：带底板的参数卡，数字滚到位后变强调色并响一声
- `scan(t, t0, 区域)` 扫描线；`compareBar(t, t0, {a, b, labelA, labelB, unit}, x, y, w)` 新旧对比横条并标出差值；`tag` 带底板的一行字
- 线框路径：`shape.line/poly/arc/circle/rings/rrect/teeth/thread/spring/hatch/curve/move`
- 限制：只有平面侧视线框，不能转动；通用组件和封面也会用强调色，所以章节条建议关掉

## ui 活体录屏

- `shot(t, keys, fn)`：录屏镜头，一镜到底推拉平移，`fn` 里用界面坐标画
- 控件（都带状态参数）：`win(x, y, w, h, {title, k}, fn)`、`tabBar`、`field({placeholder, focus, filled})`、`button(…, {state:'idle|hover|down|off'})`、`listRow({k, checked, flash})`、`toggle`、`panel({k, from}, fn)`、`loading`、`progress`
- `cursor(t, [{x, y}, {t, x, y, d, pause, click}, …])`：指针先快后慢、停一下再点、带涟漪和声音；`stateOf(t, 路径, x, y, w, h)` 由指针路径推出控件此刻是悬停还是按下；`clicks`、`cursorAt`
- `typeIn(t, t0, '文字', x, y, {rate})` 逐字打字加光标；`spotlight(t, t0, t1, x, y, w, h)` 压暗其余区域；`badge('演示画面')` 固定角标
- 规矩：讲真实产品时不编造功能、不改按钮名；界面外观、图标、名字不模仿任何真实软件
- 限制：没有滚动、拖拽、下拉、右键菜单、输入法候选、多行输入

## stick 简笔角色故事

- `stick(t, x, y, {pose, face, talk, scale, flip, seat})`：简笔人，x,y 是脚下；`pose`、`face` 写名字或关键帧 `[[时刻,'名字'],…]`，到点 0.07 秒切过去；返回头、手、胯的坐标（道具画在 `hand`）
- 姿势 `stand walk point raise shrug facepalm cheer panic sit sitthink think fold drop lift peek fall lie reach slap`；表情 `plain smile shock sad smug sleep blank`；`POSES` 是关节表，照着加
- `beats(t, [{at, fn(u,i), cam}])`：一句一镜，硬切，镜头里不推不摇
- `say(t, t0, '对白', x, y, {to, mode:'bubble|shout|line'})` 对白框（尾巴指向 `stick()` 的返回值）；`emote(t, t0, 'sweat|bang|heart|question|zzz|spark|dots', x, y)` 情绪符号
- `prop(name, x, y, {hot, t, …})` 道具（桌、电脑、手机、门、杯、箱、窗、床、钟、闹钟、灶、锅、碗、面、筷子、凳子），`hot:true` 用强调色，只给关键道具
- `hold(t, t0, d, fn, {z, lines})`：包袱落下后整镜冻住 d 秒（至少 0.9），可一下切近、补撞击线
- 规矩：七成时间画面定住；强调色全片只给一种东西；人物是本包自己设计的，不画任何已有的角色

## host 讲解员串场

- `host(t, x, y, {pose, talk, at, look, flip, scale, clip})`：讲解员，`pose` 为 `stand|point|present|think|shrug|wave|count|cross|open` 或关键帧；`point` 时手臂按 `at` 算角度；返回指尖、手、头、嘴的坐标
- `layout(t, [{at, mode:'left|right|corner|close', side, fn(R, L)}])`：按时刻硬切版式；`fn` 拿到图表区域 `R`，用 `L.host({…})` 在这个版式的位置画讲解员
- `stagePanel(t, t0, R, {title, tag})` 图表承托板，返回板内区域（通用的 `barChart`、`bigNumber`、`specTable` 画在里面）；`pointTo(t, t0, h, [x,y])` 指尖到目标的虚线和目标圈；`speechTag(t, t0, '关键词', h)` 讲解员旁的一行关键词
- 规矩：全片同一个讲解员；版式至少轮换三种；讲真实企业时讲解员只串场，不扮演企业里的人

## engrave 铜版画

- `plate(t, t0, {x, y, w, h, no, head, title, note})`：压出版痕、刻双线框；版痕向外多占约 70 像素，底边到 `y+h+90`，让它停在 960 以上
- `etch(t, t0, dur, 路径, {lw, seq})` 刻轮廓；`hatch(t, t0, dur, 区域, {angle, gap, cross, rings, along, dots, shade, light, cut})` 铺排线，明暗等于线宽，暗处加交叉线，`cut` 以下留白当高光
- `callNo(t, t0, 编号, [部件点], [圈心], '说明')` 引线加编号圈；`loupe(t, t0, [cx,cy], 半径, 倍数, 画细节的函数, {src, label})` 圆形放大框，里面线宽自动除以倍数
- `tint(t, t0, dur, 区域, 颜色)`：一道湿边扫过去的水彩，正片叠底，排线照样看得见；全片一两种颜色
- `S` 取形工具，`on(ctx, fn)` 封面里用；颜色常量 `INK TONE COPPER STEEL PAPER`

## woodcut 木刻版画

- `print(t, t0, fn, {t1, mode:'block|paper'})`：印一张；相邻几张首尾相接就是硬切，每张墨色不匀、轻微错位
- `gouge(t, t0, dur, 点组, {w0, w1})` 一刀；`carve(t, t0, dur, 区域, {angle, gap, flow, tone, order})` 一组刀痕把区域刻亮，`flow` 让刀痕顺着形体弯，`tone` 控制粗细做明暗
- `spot(t, t0, 区域)` 那唯一的一处颜色，像第二块色版滚上去；`title(t, t0, '字', x, y, 字号)` 刻字；`rain(t, t0, {…, keep})` 风雪雨，`keep` 给字留地方；`solid(区域)` 留黑做剪影
- 主题 `woodcut` 缺省是木版本身；`themePatch:{mode:'paper'}` 整片换成纸本，`themePatch:{a1:'#c4952f'}` 换颜色
- 限制：`title` 不能画进封面（`on()` 不支持带字的）

## dossier 案卷

- `folder(t, t0, {label, sub, tabs, openAt, closeAt, seal})`：档案夹封面、标签页、翻开和合上
- `card(t, t0, {no, total, title, evidence, line, verdict, at, out, pre})`：一张卡按“标题 → 证物 → 结论”出；证物三种：`image` 网点图、`quote` 原文纸条（可涂黑一段）、`text` 记录单
- `verdict(t, t0, '不实')` 砸章；`tally(t, t0, [{label, verdict}])` 清单逐行打出、逐行盖小章；`halftone`、`redact`、`typed`、`tag`、`sheet`
- 规矩：红色只给结论章；每张卡 2–4 秒、只放一条说法；结论章的字要和断言台账里的结论一致，查不实的说法也要在台账里写出处
- 注意：下一张卡用 `pre` 提前垫在底下，所以场景里后出的卡先画

## industry 产业图谱

- `chainMap(t, t0, {tiers:[{name, items}], focus, focusAt, label, flow})`：产业链层级图，一层层从左到右展开，到 `focusAt` 点亮这家公司所在的那一格
- `robotBody(t, t0, {x, y, h, hi, labels, raise})`：自己设计的通用人形机器人线稿，按顺序点亮关节（肩、肘、腕、手、髋、膝、踝、腰、颈）并引出标签——讲“这个零件装在哪”；`raise`（0..1）让右臂抬起，旁白说“抬手”时画面要跟上。标签会自动加关节名前缀（“腕 …”），说明写短语，别再重复关节名
- `exploded(t, t0, dur, layers, {focus})`：零件爆炸图再归位；层的形状有外壳、圆环、内齿圈、柔轮、齿轮、波发生器、圆盘、轴，谐波减速器、行星减速器都拼得出来
- `shareRing(t, t0, [{name, value}], {focus, source})` 份额环（不给 `source` 自动写“示意数据”）；`vsLocal(t, t0, {left, right})` 进口 / 国产两栏对比；`iconWall(t, t0, [{icon, label}])` 下游应用图标墙
- `heading`、`badge`（“示意图，未按比例”“虚构企业”这类小注）、`icon`
- 组件只用主题颜色，换成 `blueprint`、`swiss`、`holo` 也能用；题材规矩见 `题材模板.md` 第 14 张卡
- 规矩：不画真实企业的标志和产品外观（用通用线稿，标“示意”）；份额、营收一律来自断言台账，并注明口径和年份；份额环里推算出来的“其他”写“其他（推算）”
- 第一条成片《一圈会弯的齿》（绿的谐波）里自己画的谐波啮合示意 `mesh()` 在项目的 `scenes.js` 里：刚轮固定、柔轮按不可伸长薄环变形、齿差 2，长轴处的齿总落进齿槽。下次讲谐波还要用，就收进包里

## art 艺术引擎

不是一套“长相”，是一层画法：别的包、通用组件画出来的任何画面，都可以再过一遍它。`"packs":["glow","art"]` 这样和别的包并列加载。完整说明在 `kit/packs/art.js` 开头。

- `look('名字', t, {mix, rect})`：把这一帧已经画好的东西重绘成一种画法——`vangogh` 旋动短笔触、`impression` 印象派色点、`pointill` 点彩、`mosaic` 马赛克、`halftone` 印刷网点、`pixel` 像素、`cubist` 立体切面。`mix` 从 0 推到 1 就是“画面变成一幅画”。**文字一律在 look 之后画**，不然字也被重绘
- `look('名字', t, {draw(tt){…}, fps})`：步进重绘，只重绘 `draw` 里画的，画面按 fps 一顿一顿地走；整片都重绘的片子用这个（一帧重绘 0.1–0.3 秒，步进形式同一步里不重算）
- `post('名字', t, {…})`：叠一层媒介——`film` 老胶片、`vhs` 录像带、`bloom` 泛光、`vignette` 暗角、`fade` 褪色、`scan` 扫描线、`rgb` 三色错位、`flare` 镜头光晕、`light` 明暗法（整幅乘一张光照图）
- `trans('名字', t, 切点, 时长, 画A, 画B, {…})`：45 个转场，用法和通用的 `xfade` 一样；`seq(t, 第一场, ['名字', 切点, 时长, 下一场], …)` 把一串场景依次接起来。写在 `scenes(t)` 最外层，不放进 `scn()`
- 库：`P` 绘画（毛笔飞白、墨晕、水彩、厚涂、赛璐珞、长影子、皮影、纸纹）、`MO` 动效时间（弹簧、步进、错开）、`CAM` 世界相机（视差、对数缩放）、`DG` 图解（逐笔描出、形变、公式）、`TY` 文字动效、`CH` 图表、`UI` 发布会界面、`CL` 拼贴、`TOON` 扁平插画
- 限制：重绘和后期只能画在和画面一样大的画布上；`film`、`vhs` 整屏在闪，一条片用在一两段，动效检查会把闪的那几帧报成“跳变”，看过保留即可；上游的 35 个风格场景、角色、八种参数化片段没有收（原因见 `UPSTREAM.md`），角色用工坊自己的 stick、host
- 库里逐字、打字出现的字只登记得到当时画出来的那一截，这种地方自己补 `if(REC) recText('整句', x, y, 字号, 对齐)`，阅读时长检查才算得对

## 剪辑素材（不是风格包，任何风格都能用）

收集来的视频重新剪辑，用通用组件 `clipFull`（满屏片段）、`clip`（框里的片段）、`xfade` / `dipTo` / `wipe`（转场）、`clipSound`（原声单独一轨，J/L 剪接），配合命令 `transcribe`（把素材转成逐字稿）和 `pick`（给镜头打分、出联系表）。用法和授权规矩见 `素材与剪辑.md`，样片在 `kit/gallery/recut/`。

## 做包时踩过的坑

- 相交的形状要分别填色：两个形状叠在一起用一条路径 `fill()`，按非零规则或奇偶规则，重叠的地方会被挖空或填成一块；要分开的颜色，就分开画两次。
- 包组件里的字都要登记给检查（`recText` 或 `txt`），否则阅读时长和重叠检查看不见它。
- 更多见 `新风格包任务书.md` 末尾“前一批同事踩过的坑”。
