# 经验库

每条片子踩过的坑记在这里。**state** 说明这条经验现在落在哪：
- `check`：已经变成自动检查（最牢靠）
- `template`：已经写进模板或组件的默认值
- `flow`：已经写进制作流程（skill 的步骤）
- `note`：只是提醒，靠人记得——**同一类问题第二次出现，就必须升级成前三种之一**

新增一条：`python3 kit/workshop.py lesson "教训" --from 片名 --state note`

| 编号 | 教训 | 出自 | state | 落在哪 |
|---|---|---|---|---|
| L-001 | 稿子没过独立审稿就去配音，审出问题后八句重配 | 轴承为什么省力 | flow | 审稿排在配音之前，不许跳 |
| L-002 | 传到电脑的文件是旧版本，配音念了旧稿 | 天为什么是蓝的 | flow | 传文件用新文件名，传完在电脑上核对内容 |
| L-003 | 读错一个字，回听分数照样很高 | 天为什么是蓝的 | check | 配音回听：任何差异都列出来请人听 |
| L-004 | 倍数说大了、“算清楚”其实是“最早算出” | 天为什么是蓝的 | check | 断言台账 + 最高级说法检查 + 独立审稿 |
| L-005 | 字出来没多久就消失，读不完 | 天为什么是蓝的 | check | 阅读时长；稿子里用 hold 多留几秒 |
| L-006 | 旁白在说，画面四秒以上不动 | 天为什么是蓝的 | check | 画面空档 |
| L-007 | 两边条件不对等的对比（干摩擦对润滑轴承） | 轴承为什么省力 | flow | 审稿要点：对比两边条件要对等，数字用厂家给的范围 |
| L-008 | 圆角矩形自己另起路径，镂空填充出斜线 | 轴承为什么省力 | note | 画镂空形状用 g.roundRect，不用 rr() |
| L-009 | 旧片章题的年号只有 21 像素 | 东坡 | template | 水墨包 chapter、石印包 dateHead 默认 32；小字检查兜底 |
| L-010 | 毛笔体只带了旧片用过的字，新字会悄悄变成楷体 | 收编旧片 | check | 字体缺字 |
| L-011 | 每次命令都重写 timeline.json，整片扫描的缓存次次作废 | 收编旧片 | template | 内容没变就不重写 |
| L-012 | 拨弦配乐峰值超过 -1.5 dBTP | 收编旧片 | template | 混音末端加限幅 |
| L-013 | 风格包里的名字和通用组件撞名（stamp、lerp） | 收编旧片 | template | 用风格包的 scenes.js 整份包在一个函数里；印章用 sealStamp |
| L-014 | 旧片只为那一条片写，地名表、章节、里程都写死在画法里 | 收编旧片 | flow | 复盘时逐个函数决定去向；沉淀时把写死的内容变成参数 |
| L-015 | 毛笔体按字分成很多小文件，没装完就开画：新字第一次出现会先用楷体，还被缓存住；回归样张时好时坏 | 收编旧片 | template | 水墨包开画前装齐全部字体文件；回归样张把它暴露出来 |
| L-016 | 回归比较用整张平均差，小改动（地名字号）测不出来 | 收编旧片 | check | 改成分块取最大差 |
