# 叙事与创意：从一句提示词到一条有自己样子的片子

题材卡管“这类内容别讲错”，风格包管“画面长什么样”。这份管的是最容易千篇一律的那部分：**这一条片子从哪个角度讲、按什么顺序讲、用什么声音讲**。

做法只有一条：**先想清楚“这一条为什么要这样讲”，再去套题材卡和风格**。题材卡里的节拍是兜底的骨架，不是每条片都照着走的流水线。

---

## 一、拆提示词（立项第一步，五分钟）

用户的提示词往往只有一两句。把它拆成下面这张表，写在项目的 `导演阐述.md` 开头。拆不出来的格子，先按“隐含信号”补一个最可能的，标上“推断”。

| 格子 | 问自己 | 从提示词里找什么 |
|---|---|---|
| 讲什么 | 主题和对象：一个人、一个零件、一件事、一个现象 | 名词 |
| 给谁看 | 年龄、懂多少、在哪刷到 | “给孩子”“给同行”“发抖音” |
| 要观众带走的一句话 | 看完能复述的那一句 | 用户自己的判断、形容词 |
| 情绪 | 好奇、燃、温情、悬疑、荒诞、庄重…… | 语气词、形容词、参考片 |
| 平台和长度 | 横版长片 / 抖音 / 小红书 / 视频号 | 平台名、“短一点” |
| 参考 | 像哪条片、哪个人、哪种风格 | “像东坡那条”“像某某频道” |
| 禁区 | 不能说的、不能出现的 | “别煽情”“不要卡通” |
| 必须有 | 指定的事实、镜头、素材、口号 | 用户给的材料 |

**隐含信号**（用户没说，但提示词透露出来的）：

| 提示词里的信号 | 往往意味着 |
|---|---|
| 一个具体的人名、地名、年份 | 想要故事，不是百科：找“这个人在某一刻做了什么选择” |
| “讲清楚”“为什么”“原理” | 想要问题链或拆解：每一步都要回答一个“为什么” |
| “燃”“热血”“逆袭”“国产” | 想要冲突和反转，但事实不能为情绪让路（份额、排名最容易说过头） |
| “温情”“怀旧”“一封信”“老物件” | 想要慢、留白、少数字：器物视角、书信体、无旁白段落 |
| “悬疑”“谜”“真相” | 悬念倒叙：先给结果或异常，再倒回去 |
| “搞笑”“吐槽”“打工人” | 第一人称、简笔角色、包袱后定住 |
| “发抖音 / 小红书 / 视频号” | 竖版、前 2 秒必须有钩子、一条只讲一件事（见 `竖版与平台.md`） |
| “像某某那条” | 只学它的骨架（顺序、占比、节奏），不学它的皮肤（配色、角色、原话） |

提示词太短、拆完还有三个以上格子是空的：用户在场就问一到三个问题（给选项，别让人写作文）；不在场就按最可能的补上，在交付说明里写明“这几处是我推断的”。

## 二、三个方向，至少三样不同

拆完先别写稿。写**三个创意方向**，每个四五行。三个方向在下面五样里**至少有三样不同**，否则只是同一个方向的三种说法：

1. **视角**：谁在讲？离事件多远？（旁观的讲述者 / 当事人第一人称 / 一件物品 / 一份档案 / 后人回看）
2. **结构**：从第三节的手法库里选一种，或者写明自创的
3. **钩子**：开场 2–3 秒是什么画面、什么话
4. **声音**：谁来念、什么语气、多快、哪里不说话
5. **画面母题**：全片反复出现、最后回扣的那个东西（一张地图、一封信、一个齿轮、一扇门）

每个方向用这张卡写：

```
方向 A：一句话（logline，50 字以内：讲什么 + 为什么值得看）
视角：……　结构：……　钩子：……
情绪曲线：好奇 → 紧张 → 意外 → 释然（四五个词）
声音：哪个声音，什么语气，快慢；哪一段不说话
画面母题：……　结尾回扣：开头那个东西怎么回来
风格包：……　风险：最可能出错的地方
```

选一个，写一句为什么选它、为什么不选另外两个。用户在场时，三个方向可以直接摆给用户挑（这一步比改片便宜得多）。选中的写进 `brief.json` 的 `direction`，另外两个写进 `direction.alternatives`：

```json
"direction": {
  "logline": "一封二十年没寄出的信，背面早有回信",
  "angle": "旁观者讲一个人的二十年",
  "structure": "悬念倒叙·一物一史",
  "hook_type": "悬念物件",
  "emotion": "好奇→压抑→意外→释然",
  "motif": "信封",
  "callback": "信",
  "alternatives": ["第一人称：他自己讲这封信", "书信体：直接念信的三行字"]
},
"voice": {"model": "google/gemini-3.8-flash-tts", "voice": "Charon", "style": "温和、平静，语速稍慢", "persona": "讲故事的人，不煽情"}
```

`check` 会核对：`logline` 写了没有、是不是一句话说得清；比没比过别的方向；**和台账里最近六条片子比，视角、结构、钩子、声音、风格五样里有三样一样就提醒“太像了”**（台账 `films` 在复盘时自动记下每条片的这五样）。

## 三、叙事手法库

不是模板，是“这样讲会发生什么”的经验。每种都写了适合什么、骨架、钩子怎么写、常见的坑，以及工坊里用过它的片子。可以组合（“悬念倒叙 + 一物一史”）。

### 1. 一物一史
让一件东西串起一段历史或一个行业。**适合**：零件、器物、文物、老物件、企业的拳头产品。**骨架**：这件东西现在在哪（钩子）→ 它解决了什么难题 → 它从哪来 → 谁把它做成今天这样 → 它还缺什么 → 回到开头那个位置。**钩子**：特写这件东西在一个看得见的整机或生活场景里。**坑**：变成产品说明书；东西本身没有变化和难处就没有戏。**用过**：《一圈会弯的齿》（谐波减速器 → 绿的谐波）。

### 2. 问题链
一个问题的答案引出下一个问题。**适合**：科普原理、“为什么”。**骨架**：一个人人见过却答不上来的问题 → 第一个答案 → “那为什么……？” → 第二个答案 → … → 回到开头的问题，用全部答案合起来回答。**钩子**：把问题直接问出来，配一个反常的画面。**坑**：问题之间没有因果，只是并列的五个知识点。**用过**：《天为什么是蓝的》。

### 3. 拆解
把一个整体一层层打开。**适合**：工业零部件、产品、机构、系统。**骨架**：完整的东西 → 打开第一层 → 每层只回答一个问题 → 合上，再看它就不一样了。**钩子**：“这东西你每天都在用，但你没见过它里面。”**坑**：一层层报零件名，没有“为什么要这样设计”。**用过**：《轴承为什么省力》。

### 4. 旅程 / 地图
跟着一个人或一样东西走一条路，地点就是章节。**适合**：人物一生、迁徙、贸易路线、一件货物的旅行。**骨架**：起点 → 每一站发生一件改变他的事 → 终点回望整条路。**钩子**：终点的一个画面，或者地图上一条还没画完的线。**坑**：每站都一样重，变成流水账；地名年份太密。**用过**：《东坡》（一张地图讲一生，无旁白）。

### 5. 日记体 / 书信体
用当事人留下的文字推进，旁白退到最少。**适合**：有日记、书信、奏折、笔记留下来的人和事。**骨架**：一页一页翻，原文 + 一句旁白点出“这一页发生了什么”；最后一页留白。**钩子**：最反常或最动情的那一句原文。**坑**：原文太长念不完；原文要进断言台账（quote）。**用过**：《河海昆仑录》（跟着一本日记走一条路）。

### 6. 双线对照 / 小人物与大时代
两条线并行，最后交汇或形成反差。**适合**：普通人和历史事件、两家公司、两种技术、过去和现在。**骨架**：A 线一段 → B 线一段 → 交替越来越快 → 交汇点 → 交汇之后各自的结局。**钩子**：两条线最不像的一刻并排放。**坑**：一条线明显更弱，观众只等另一条；切换没有理由。**用过**：《王钟儿》（漆屏风上下两栏）。

### 7. 悬念倒叙
先给结果或一个异常，再倒回去讲怎么会这样。**适合**：事故、谜团、反常的数据、出人意料的结局。**骨架**：异常 / 结果（钩子）→ “这要从……说起” → 按时间推进，每段埋一个线索 → 线索在揭示时合上 → 回到开头的画面，这次看懂了。**钩子**：结果的画面 + 一个问题。**坑**：揭示靠旁白硬讲，前面没有埋线索；悬念是装出来的（答案大家都知道）。**用过**：竖版样片《一封没寄出的信》。

### 8. 器物 / 第一人称视角
让一件东西、一个零件、一只动物来讲。**适合**：拟人化的科普、企业产品、轻松题材。**骨架**：“我是……” → 我每天在干什么 → 我最难的时候 → 谁造了我 → 我想让你知道的一件事。**钩子**：一句出人意料的自我介绍。**坑**：拟人化过头变幼稚；新闻和真人题材别用。

### 9. 对质 / 审判
把两种说法、两份数据、两个立场摆上台，一条一条对证据。**适合**：谣言核查、争议、份额和排名打架、“到底谁说得对”。**骨架**：两种说法 → 证据一 → 证据二 → 证据之间的矛盾 → 能下的结论和下不了的结论。**钩子**：两种说法并排，中间一个问号。**坑**：假装中立其实早有结论；证据不对等。**用过**：《一圈会弯的齿》后半段（三份份额数据）、案卷风格包。

### 10. 倒计时 / 时间压缩
把一段时间压成一个倒计时或一天。**适合**：发射、比赛、生产一件东西的 24 小时、一个人的最后一年。**骨架**：起点时间 → 每个时间点一件事 → 时间越来越紧 → 到点。**钩子**：屏幕上的时钟和一句“还剩……”。**坑**：时间点之间没有因果，只是日程表。

### 11. 数字串
一个数字引出一个故事，再引出下一个数字。**适合**：数据解读、企业介绍、年度回顾。**骨架**：一个反常的数字 → 它背后的事 → 由此引出的第二个数字 → … → 最后一个数字回答第一个。**钩子**：一个大到或小到反常的数字。**坑**：数字太多记不住（一屏一个，一句一组）；每个数字都要进台账。

### 12. 你以为…其实…
从一个常见误解出发，一步步纠正。**适合**：科普辟谣、“冷知识”、行业误区。**骨架**：误解（大家都这么想）→ 第一个反例 → 真正的原因 → 为什么误解会流行 → 正确的说法。**钩子**：把误解当真说出来，再停一拍。**坑**：误解是自己编的稻草人；纠正之后没有新东西。

### 13. 清单体（N 件事）
**适合**：竖版短片、实用信息、“三个原因”。**骨架**：一句总起 → 1、2、3（每条一屏，一个画面）→ 最重要的放最后。**钩子**：直接说“X 件事”，第一条立刻上。**坑**：条与条之间可以随便调换顺序，说明没有递进。

### 14. 问答 / 访谈体
**适合**：有采访素材、或者用两个声音一问一答讲复杂事。**骨架**：问题 → 回答 → 追问 → 回答……问题本身就是结构。**钩子**：最尖锐的那个问题。**坑**：问题太软；回答太长没有剪。

### 宣传线的结构（`"mode":"promo"`，另见《宣传片.md》）

上面十四种是讲解和叙事用的。宣传片常用的是这几种，写进 `direction.structure`：
- **痛点—亮相—卖点—证明—口号**：最稳，产品发布用。
- **一天 / 一夜**：不讲功能，演它替人干完一件事的过程，最后才出名字。
- **数字串**：三到五个数一路砸下来，每个数一个画面，适合成绩单、周年、城市。
- **动线**：跟着一个人走进去，场景与空间用。
- **问题—方案—进度—所求**：项目推介用。
- **只露轮廓**：发布会开场片，把悬念留给台上的人。

## 四、逻辑线：讲清楚的五条规矩

故事好不好看靠创意，**讲不讲得清楚靠逻辑线**。写完稿按这五条过一遍，再交给独立审稿：

1. **一问一答成对。** 开头抛出的问题（钩子）在结尾之前必须回答。稿子里给提问的那句标 `"ask":"问题名"`，回答的那句标 `"answer":"问题名"`；`check` 会查有没有问了不答、先答后问。
2. **每一章回答一个问题。** 章节标题写成问题（或在导演阐述里写出来），这一章结束时这个问题有答案。答不出“这一章回答了什么”，这一章就该删或并。
3. **因果不跳步。** 相邻两句之间能加“所以”“但是”“于是”之一；加不上的地方，要么少了一步，要么顺序错了。
4. **中段要有一次转折或揭示。** 观众要有一次“原来如此”或“没想到”。没有的话整条片是平的。稿子里标 `"beat"`：钩子 / 铺垫 / 推进 / 转折 / 揭示 / 高潮 / 回扣 / 收束；`check` 会看中段有没有转折、揭示或高潮。
5. **结尾回扣开头。** 开头那个画面、那个物件、那个词，结尾回来，而且意思变了。`direction.callback` 写这个词，`check` 会查它在前三句和后三句的旁白里都出现。

## 五、声音也要跟着方向走

同一个声音、同一个语速念所有片子，是“千篇一律”最快被听出来的地方。

- **先定人设，再选声音**：讲述者是谁？（不动声色的讲故事的人 / 热心的老师 / 冷静的调查记者 / 当事人自己）写进 `brief.voice.persona`。
- **试音**：`python3 <工坊>/kit/tts_openrouter.py voices google/gemini-3.8-flash-tts Charon,Kore,Puck,Sulafat "片子里最有情绪的那一句" "语气提示"`，用户听过再定。Gemini 的这几个声音 2026-10 实测都能用；声音的性格要听，不要凭名字猜。
- **全片语气**写 `brief.voice.style`（如“温和、平静，语速稍慢”）；**个别句子**写 `"tone"`（如转折那句“放慢、放轻，带一点意外”）。`build.py lines` 会把它写进 `lines.txt` 的第三栏，配音脚本走接口的 `instructions` 字段。实测（Gemini Charon）：语气提示会让声音变低、变慢，**提示本身不会被读出来**。**千万不要把提示写进朗读文本前面**，那样会被原样念出来（实测过）。
- **留白也是声音**：转折前多留半秒（`hold`）；最动人的那句之后不说话；整段可以无旁白（`silent`），只有画面和配乐。
- **快慢跟着情绪**：讲原理时稳，揭示前慢，清单体快；同一条片里不要从头到尾一个速度。
- 回听照样跑：语气提示可能让个别字读得含糊，回听会报出来。

## 六、不千篇一律：每次立项前对一下

- 看台账 `films` 最近六条：视角、结构、钩子、声音、风格。新片在这五样里至少换掉三样（`check` 会提醒）。
- 同一题材连做两条时，第二条换结构（第一条拆解，第二条就别再拆解）。
- 同一个用户连续几条用同一个声音，问一句要不要换。
- 风格包不是越多越好：一条片一种主风格；换风格不等于换了讲法。
- 收工复盘时把“这次哪里像以前”写进复盘的“模板哪里别扭”一节。

## 七、导演阐述（每条片一页）

立项结束时在项目里写 `导演阐述.md`，审稿和审片的人照着它判断片子有没有做到：

```
# 导演阐述 · 片名
## 提示词拆解（第一节那张表）
## 三个方向（第二节的卡，标明选了哪个、为什么）
## 逻辑线：钩子问题 → 每章回答什么 → 转折在哪 → 结尾怎么回扣
## 声音：人设、声音、语速、哪几句有特别的语气、哪里不说话
## 画面：主风格、画面母题、招牌镜头（全片最想让人截图的那一帧）
## 平台：横版 / 竖版（见 竖版与平台.md），长度
```
