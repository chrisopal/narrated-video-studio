# 素材与剪辑

## 什么素材能进成片（硬性规矩）
`assets.json` 的 `usage_basis` 只接受下面八种，别的一律不过检查：

| 值 | 含义 | 还要填 |
|---|---|---|
| own | 自己拍的、自己做的、企业自有 | source 写拍摄人和日期 |
| licensed | 已获书面授权 | proof 写授权人、授权范围、日期；proof_file 放授权凭证文件；credit |
| public-domain | 公有领域（如 NASA、美国联邦政府作品、版权已过期） | source 网址 |
| cc0 | CC0 | source 网址 |
| cc-by | 署名 | credit |
| cc-by-sa | 署名并相同方式共享 | credit；成片相应部分也要同样共享 |
| stock-free | 免费图库许可（Pexels、Pixabay、Mixkit、Coverr 等） | source 网址 |
| excerpt | 引用片段：网上下载的企业宣传片、发布会、展会、报道里的一小段，为介绍和评论而引用 | source 写下载页面网址；owner 写版权方；credit 写画面上的来源（不用加“影像：”，组件会加） |

- **企业宣传片、发布会视频、产品视频、媒体报道、平台上别人的视频，版权在对方。** 两条路：
  - 拿到书面授权（最稳妥）：`usage_basis` 写 `licensed`，台账里写清授权人、范围、日期，并把凭证文件（授权书扫描件、授权邮件）放进项目、`proof_file` 写路径。授权要写什么见 `来源与许可.md` 的“企业素材授权”。
  - 用户决定直接引用（`excerpt`）：只取说明问题的短片段，画面上标来源。检查会拦：每段超过 15 秒不通过（brief 的 `excerpt_max` 可调），引用合计超过全片 30% 提醒（`excerpt_share`）；没有下载网址、没有版权方也不通过。引用要为讲解服务：旁白在讲它、画面在分析它，不能整段搬过来当主体。
  - 注明来源不等于获得授权。交付时要告诉用户哪些是引用片段、来自哪里；对方提出异议就撤下或补授权。要商用、投放广告的片子，引用片段换成授权素材。
- 电影、电视剧、综艺这类作品不用 `excerpt`，只拉片。
- 工具箱不带从视频网站批量抓取视频的功能。下载的视频由用户放进项目的 `footage/`（或他电脑上的文件夹）；需要我去下载时，先把文件名、来源、大小告诉用户并得到同意。

## 台账 assets.json
```json
[{"id":"lathe","type":"video","file":"footage/车间_01.mp4","in":12.4,"out":18.0,
  "title":"数控车床车外圆","creator":"某某公司","source":"2026-09 厂内拍摄","usage_basis":"own",
  "credit":"某某公司提供","fit":"cover","size":[1280,720],"note":"为什么是这一段"},
 {"id":"ceo","type":"video","file":"footage/发布会.mp4","in":"@s3","out":"@s5",
  "title":"发布会上总经理介绍新产线","creator":"某某公司","source":"某某公司 2026-05 发布会录像","usage_basis":"licensed",
  "proof":"某某公司品牌部张某，2026-09-20 邮件授权：可剪辑后在视频平台发布，期限两年，署名“某某公司提供”","proof_file":"授权/某某公司_授权邮件.pdf","credit":"某某公司提供"},
 {"id":"portrait","type":"image","file":"img/x.jpg","creator":"…","source":"https://…","usage_basis":"cc-by","credit":"…"}]
```
- `fit`（切片时）：cover 裁满，contain 留边，blur 模糊垫底。`size` 默认 1280×720，要铺满全屏写 [1920,1080]；竖拍素材写成竖的尺寸（如 [608,1080]），放进横框时在 `clip()` 里用 `fit:'blur'`。
- `in` / `out` 写秒数，或者写 `"@s3"` / `"@s5"`：第 3 句开头到第 5 句结尾（先运行 `transcribe`，见下）。切片时自动换算成秒，在句子边界外各留 0.12 秒，不越过相邻句子的中点。

## 步骤
1. 把原始视频放进项目的 `footage/`，运行 `python3 ../kit/build.py probe`。得到每条素材的时长、尺寸、方向、切点、静音段，以及带时间码的联系表（`footage/_sheets/`）。看联系表，读图上的秒数。
2. 素材多、长的时候先让机器挑一遍：`python3 ../kit/build.py pick 文件名 [个数]`（见下）。
3. 有人讲话的素材先转写：`python3 ../kit/build.py transcribe 文件名或素材id`，按句子定入出点（见下）。
4. 为每一拍选片段，写进 `assets.json`。选法：
   - 先写这一拍“观众要看到什么”，再去找画面；不是有什么放什么。
   - 找一条素材里最好的那几秒，不用整段。晚进早出，但动作和一句话必须完整。
   - 入出点避开切点前后 4 帧；有人说话的片段，入出点落在句子边界（`@s` 写法）或静音段里。
   - 模糊、抖动、过曝、被遮挡、转场中间的帧不用。
   - 每个片段记一句“为什么是这一段”（写在 note 里）。
5. `python3 ../kit/build.py clips`：帧精确切片，统一成 30 帧，拆成逐帧图片和一条原声。所有入出点先算一遍、查一遍，有错一条都不切。
6. 在 scenes.js 里放片段（见“画面”“转场”“声音”）。在片段上加 `callout`、`highlight`、`lowerThird` 讲解，这些是独立的层，不改原画面。
7. `check` 会查：台账字段齐不齐、依据是否允许、需要署名的有没有署名、授权素材有没有凭证文件、画面用到的片段是否都在台账里。`final` 会生成 `素材来源与授权.txt`。

## 挑镜头 `pick`
`python3 ../kit/build.py pick 文件名 [个数]`（文件名或素材 id，个数缺省 8）
- 用切点把素材分成镜头，长于 6 秒的镜头按约 4 秒分段；每段抽样（每秒 5 帧，素材超过 10 分钟每秒 2 帧）打分：清晰度 .35（拉普拉斯方差，一半看绝对值、一半看在这条素材里的排名）、亮度 .25（太暗、太亮、大片死黑死白扣分）、运动量 .25（适中满分；几乎不动给一半，可以配推拉摇；晃得厉害或中间闪一下扣分）、时长 .15（不到 2 秒总分减半）。
- 终端列出前 N 个候选：镜头号、起止时间码、时长、分数和各项分、可直接抄进台账的 `"in":…,"out":…`（真切点两侧已经让开 4 帧）。
- 出一张联系表 `footage/_sheets/<名字>_pick.jpg`：每行一个候选，入点、中间、出点三帧，图上有时间码；明细在 `<名字>_pick.json`。
- 只做建议，不改台账。分数看不出内容对不对，选哪段还要人看图定。

## 按讲话内容选入出点 `transcribe`
`python3 ../kit/build.py transcribe 文件名或素材id`
- 用和配音回听（`asr.py`）同一个离线识别模型，把素材的声音转成带时间的文字，按停顿（模型给出标点时也按标点）切成句子，写到 `footage/<名字>.transcript.json`（`sentences`：每句 `n` 编号、`start`/`end` 秒、`text`），终端打印“编号 起–止 文字”清单。
- 台账里 `"in":"@s3","out":"@s5"` 就是第 3 句开头到第 5 句结尾；只要一句就写 `"in":"@s3","out":"@s3"`。素材文件改过，旧转写会被拒绝，重新跑一次。
- 识别会有错字（尤其人名），转写只用来定时间；字幕和引文要对着原声核对，引语还要进断言台账（status: quote）。
- 没有模型时命令会提示怎么装（流程.md「环境、依赖、密钥」里的下载命令），不会崩溃。

## 画面：`clip()` 和 `clipFull()`
```js
clip(id, t, t0, x, y, w, h, {from, speed, sound, fit, kb, fade, t1, r, frame, col, credit, creditLift})
clipFull(id, t, t0, t1, {…同上})        // 铺满画面、无边框、无圆角，署名抬到字幕带上方；t1 写 null 就放完停在最后一帧
```
| 参数 | 作用 |
|---|---|
| `from` / `speed` | 从片段第几秒起放；变速（原声不变速，变速的片段一般不放原声） |
| `fit` | `'cover'` 裁满（缺省）/ `'contain'` 留黑边 / `'blur'` 用同一帧放大模糊垫底、原画居中。竖拍放进横版、横拍放进竖版都用 blur |
| `kb:{z0,z1,x0,y0,x1,y1}` | 推拉摇（Ken Burns）：片段播放期间（t0 到 t1，没写 t1 就到片段放完）从取景 (z0, x0, y0) 平滑到 (z1, x1, y1)。z 是放大倍数（≥1 不露边），x、y 是取景中心（0–1）。素材里烧进去的字幕、台标，可以用 z0≥1.2 裁掉 |
| `t1` | 片段在全片里的结束时刻：到点淡出或截止。不写就放完停在最后一帧（旧行为） |
| `fade:[入, 出]` | 淡入淡出秒数；出要配 t1（没写 t1 就在片段放完时淡完） |
| `credit:false` | 不显示右下角署名（同一画面几个框用同一条素材时，只留一处署名） |

片段放完停在最后一帧；默认在右下角显示台账里的署名；片尾用 `credits(t, t0, creditLines())` 自动列全。

## 转场
```js
xfade(t, tCut, d, drawA, drawB)              // 交叉溶解
dipTo(t, tCut, d, col, drawA, drawB, rect?)  // 经过一种颜色：黑场 '#000'、白闪 '#fff'、主题色
wipe(t, tCut, d, dir, drawA, drawB, rect?)   // 擦切，dir 是边移动的方向：'right'（缺省）'left' 'down' 'up'
```
- drawA / drawB 是两个画法函数（收到转场进度 0–1）。转场占 tCut−d/2 到 tCut+d/2；之前只画 A，之后只画 B。都是 t 的确定函数，可以任意跳帧。
- 两头的片段都要覆盖转场那一段：A 的 t1 写到 tCut+d/2，B 的 t0 写成 tCut−d/2。
- 转场写在 `scn()` 里面，不要把 `scn()` 写进 drawA/drawB（scn 会重设透明度）。转场可以嵌套（B 里再写一个 wipe）。
- 用法：叠化 0.6–1 秒，用在时间、地点的过渡；硬切是默认，同一场景里的镜头不用叠化；白闪只给“咔嚓”一类的瞬间。

```js
scn(t,T('b0'),N('b0'),()=>{const s=T('b0');
  xfade(t,s+4,1,()=>clipFull('lathe',t,s,s+4.5,{kb:{z0:1,z1:1.3,x1:.7,y1:.45}}),
                ()=>clipFull('grind',t,s+3.5,null));});
```

## 声音：谁拥有这一拍
每一拍先定谁拥有声音：
- 旁白拥有：`sound` 不写（静音）或给 0.2–0.4 当环境声。原声在旁白下面自动压低（见下），不用自己调。
- 原声拥有（机器声、现场一句话）：这一拍不写旁白，`sound:1`，并在 script.json 前一句加 `hold` 留出时间。

`sound` 写数字时，原声的截止和淡入淡出跟画面走（`t1`、`fade`）；也可以写 `{gain, t1, fadeIn, fadeOut}` 单独定。

**声音和画面分开（J-cut / L-cut）**：
```js
clipSound(id, t, t0, {from, gain, t1, fadeIn, fadeOut})   // 只登记原声，不画画面
```
- J-cut（原声先进）：上一个画面还在，下一段的原声先响，画面再切过去。原声从 t0 起放，画面晚 Δ 秒进来时写 `from:Δ` 对上口型：
  ```js
  clipSound('ceo',t,s+.4,{fadeIn:.25});
  if(t<s+1.8) clip('lathe',t,s,…); else clip('ceo',t,s+1.8,…,{from:1.4});
  ```
- L-cut（原声后出）：画面已经切到下一个镜头，上一段的原声还在，`clipSound` 的 t1 写到画面切走之后，再给一个 fadeOut。
- `check` 和 `final` 把只出声不出画的片段也算作“用到了”，同样要在台账里、同样要有依据。

**原声压低（ducking）**：`mix` 把所有片段原声放在单独一条轨上，在有旁白的地方（每句 t0+lead 到 t0+voiced）自动压低 12 dB，进出各 0.3 秒平滑；没有旁白的地方保持原声音量。最后和配乐、音效、配音一起两遍响度归一到 −14 LUFS，限幅保证真峰值不超过 −1.5 dBTP。`brief.json` 写 `"duck":8` 改压低的分贝数，`"duck":false` 不压低（原声混在音效轨里，旧做法）。

## 还没有的
- 地图底图没有内置；路线图、区位图要自己画示意或用授权清楚的底图。
- 转写不带说话人区分；几个人对话的素材，谁说的哪句要人听。
- `pick` 只看画质，看不出内容对不对、主体有没有被挡。
