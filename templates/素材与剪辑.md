# 素材与剪辑

## 什么素材能进成片
`assets.json` 的 `usage_basis` 只接受下面七种，别的一律不过检查：

| 值 | 含义 | 还要填 |
|---|---|---|
| own | 自己拍的、自己做的、企业自有 | source 写拍摄人和日期 |
| licensed | 已获授权 | proof 写谁、何时、授权范围；credit |
| public-domain | 公有领域（如 NASA、美国联邦政府作品、版权已过期） | source 网址 |
| cc0 | CC0 | source 网址 |
| cc-by | 署名 | credit |
| cc-by-sa | 署名并相同方式共享 | credit；成片相应部分也要同样共享 |
| stock-free | 免费图库许可（Pexels、Pixabay、Mixkit、Coverr 等） | source 网址 |

电视台、平台、电影、别人账号的视频，授权不明就不进成片。它们可以放进参考片单，用 `study` 拉片学结构。
下载任何素材之前，先把文件名、来源、大小告诉用户并得到同意。

## 台账 assets.json
```json
[{"id":"lathe","type":"video","file":"footage/车间_01.mp4","in":12.4,"out":18.0,
  "title":"数控车床车外圆","creator":"某某公司","source":"2026-09 厂内拍摄","usage_basis":"own",
  "credit":"某某公司提供","fit":"cover","size":[1280,720]},
 {"id":"portrait","type":"image","file":"img/x.jpg","creator":"…","source":"https://…","usage_basis":"cc-by","credit":"…"}]
```
`fit`：cover 裁满，contain 留边，blur 模糊垫底（竖屏素材放进横屏时用）。`size` 默认 1280×720，要铺满全屏写 [1920,1080]。

## 步骤
1. 把原始视频放进项目的 `footage/`，运行 `python3 ../kit/build.py probe`。得到每条素材的时长、尺寸、方向、切点、静音段，以及带时间码的联系表（`footage/_sheets/`）。看联系表，读图上的秒数。
2. 为每一拍选片段，写进 `assets.json`。选法：
   - 先写这一拍“观众要看到什么”，再去找画面；不是有什么放什么。
   - 找一条素材里最好的那几秒，不用整段。晚进早出，但动作和一句话必须完整。
   - 入出点避开切点前后 4 帧；有人说话的片段，入出点落在静音段里。
   - 模糊、抖动、过曝、被遮挡、转场中间的帧不用。
   - 每个片段记一句“为什么是这一段”（写在 note 里）。
3. `python3 ../kit/build.py clips`：帧精确切片，统一成 30 帧，拆成逐帧图片和一条原声。
4. 在 scenes.js 里放片段：`clip('lathe', t, at('c0','车外圆'), x, y, w, h, {sound:.4})`。
   - 片段从那一刻开始放，放完停在最后一帧。`from` 从片段第几秒起，`speed` 变速。
   - 默认在右下角显示台账里的署名；片尾用 `credits(t, t0, creditLines())` 自动列全。
   - 在片段上加 `callout`、`highlight`、`lowerThird` 讲解，这些是独立的层，不改原画面。
5. 声音归属：每一拍先定谁拥有声音。旁白拥有时 `sound` 不写（静音）或给 0.2–0.4 当环境声；原声拥有时（机器声、现场一句话）这一拍不写旁白，`sound:1`，并在 script.json 前一句加 `hold` 留出时间。
6. `check` 会查：台账字段齐不齐、依据是否允许、需要署名的有没有署名、画面用到的片段是否都在台账里。`final` 会生成 `素材来源与授权.txt`。

## 现在还做不到的
- 片段和片段之间的叠化、J-cut/L-cut 要在 scenes.js 里自己写透明度；没有做成组件。
- 没有按转写文本自动选入出点；有人说话的素材，需要先看联系表和静音段手动定。
- 地图底图没有内置；路线图、区位图要自己画示意或用授权清楚的底图。
