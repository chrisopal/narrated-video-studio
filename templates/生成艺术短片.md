# 生成艺术短片（数学影像）

用数学规则画出来的短片：没有旁白或只有几句字，画面是几万个点按一条条规则排出来的。宇宙、生命、智能、时间、起源与终结这类大题目适合它；片头片尾、讲数学和算法时“看它自己长出来”的段落也用它。

工具是风格包 `gen`（`kit/packs/gen.js`），样片是 `kit/gallery/gen`（《一个点》，116 秒，中英双语）。换题目、换样子时，照下面的次序走，逻辑不变。

## 这类片子靠什么成立

一条讲解片靠“我告诉你一件事”成立。这类片子没有人在说话，它靠四件事：

1. **一样东西从头用到尾。** 全片是同一批点，数目不变。观众看到的不是“下一个画面”，是“这些东西变成了另一种东西”。叙事就在这个“变”里。一换场就换一批点，片子就成了素材串烧。
2. **一场一条规则，说得出口。** “每个点朝外飞”“每个点比前一个多转 137.5°”“每个点沿连线把信号传给下一层”。说不出规则的画面是屏保，好看，但不知道在看什么。
3. **换场是换规则，不是剪切。** 同一批点从上一条规则的位置走到下一条规则的位置。观众亲眼看着星系收成一朵向日葵，这一下就是一句“旁白”。
4. **字是问题，不是解说。** 一场最多一句，问句和断言各半，只说画面里没有的东西。画面是螺旋，字不写“这是螺旋”，写“规则很少。时间很多。”

## 一、先写一句话的弧

`brief.json` 的 `direction.logline` 写成“同一样东西，从 A 经过几种样子，到 B”。最稳的结构是回环：始于什么，终于什么，中间每一场是一条规则。结尾回到开头的画面，但观众已经知道它是什么了。

换题目时只换这一句和下面那张表：

| 题目 | 那一样东西 | 弧 |
|---|---|---|
| 宇宙、智能、终结（样片） | 七万个点 | 一个点 → 炸开 → 星系 → 向日葵 → 双螺旋 → 神经网络 → 晶格 → 问号 → 噪声 → 一个点 |
| 一座城市的一天 | 五万个点（人） | 散在各处 → 沿路网流动 → 聚成几栋楼 → 散场 → 各自亮成一扇窗 |
| 语言 | 四万个点 | 噪声 → 波形 → 字母 → 一句话 → 另一种文字的同一句话 → 噪声 |
| 一个想法的传播 | 三万个点 | 一个亮点 → 网络上一跳一跳染开 → 全亮 → 一半暗下去 → 留下一条细线 |

## 二、排场次表（最要紧的一步）

动手写 `scenes.js` 之前，把这张表填满。每一行都要能回答“这一场的规则是什么”。

| 场 | 规则（一句人话） | 构型 `F.名字` | 亮出来的那一行 | 一句字（中 / 英） | 颜色 | 相机 | 能量 0–1 |
|---|---|---|---|---|---|---|---|
| 虚空 | 只有一个点 | `point` | — | 在有任何东西之前，有过一个问题吗？ / Before there was anything, was there a question? | 白 | 正对，推近 | .2 |
| 炸开 | 每个点带着自己的速度往外走 | `burst` | `p.x += p.vx * dt` | 于是，有了“有”。 / And then, there was. | 暖橙 | 慢慢拉远 | .75 |
| 引力 | 每个点朝大家的重心落，角动量让它转起来 | `galaxy` | `a = G * m / (r * r)` | 规则很少。时间很多。 | 蓝和暖黄 | 俯下去看盘面 | .8 |
| …… | | | | | | | |

规矩：

- **代码和公式只在它正好是这一场的成因时出现**，一场一行，放在角上，等宽字敲出来。它得是对的：公式进 `facts.json`（黄金角 137.5° 是 `verified`，“这不是物理模拟”是 `conceptual`）。
- **立体的构型可以转相机，平面的要正对着看。** 星系、双螺旋、晶格转起来好看；向日葵、网络、字一歪就读不出来。
- **能量曲线先起后落再收。** 配乐 `"music":"cosmos"` 照 `brief.music_energy`（每章一个数）起伏；`"bpm"` 定了，场次用 `"bars"` 定长，换场都落在小节线上。慢片 60–72 拍。
- 一场 12–16 秒。短于 8 秒，规则还没看清就换了；长于 20 秒，没有新东西可看。

## 三、写两种语言，不是翻译

中文和英文各写一遍，意思对得上，句子各自成立。`say(t, t0, t1, '中文', 'English')` 两句一起写在场景里，`brief.json` 的 `"lang"` 决定出哪一种：

| `lang` | 画面上 | 发在哪 |
|---|---|---|
| `bi` | 中文大、英文小排在下面 | 两边都发的那一版 |
| `zh` | 只有中文 | 国内平台 |
| `en` | 只有英文 | 海外平台 |

一份 `scenes.js` 出三版：改 `lang` 各渲一遍。封面文案、片尾说明也按 `LANG` 分支。代码和公式不分语言。英文句子写短，一行放得下；中文十五字以内。

要旁白时照常写 `script.json` 的 `vo`，字就不用每场都上；但这类片子多半不需要旁白，先做无声版看成不成立。

## 四、写场景

```js
const { stage, buf, F, mix, begin, draw, frame, end, CAM, say, code, eqn } = PACK.gen;
const S = stage(70000, 7), A = buf(S), B = buf(S), P = buf(S);   // 顶层建一次，全片就这一批点

scenes(t) {
  begin(t);
  frame(t, { trail: 6, shutter: .075 }, (q, w) => {        // 拖尾：过去一小段时间里的样子叠起来
    F.galaxy(S, A, q, {...}); F.phyllo(S, B, q, {...});     // 两条规则各算一遍位置
    mix(S, P, A, B, k, { stagger: .5, scatter: .2 });       // 同一批点从 A 走到 B
    draw(S, P, { cam: CAM({ yaw, pitch, zoom }), color, color2, gain: w });
  });
  end(t, { bloom: .6, grain: .05 });                        // 之后再画字
  say(t, t0, t1, '规则很少。时间很多。', 'Few rules. A great deal of time.');
}
```

整片的骨架照样片抄：一张状态表 `ST`（每条规则一个函数）、一张过渡表 `TR`（从哪个状态、几时开始、多长、路上散开多少）、每个状态的两种颜色和亮度、相机的关键帧。换内容就是换这几张表。

- **不存状态。** 每一帧的位置都是 `t` 的函数，同一时刻画两遍一模一样；不用 `Math.random`，不靠上一帧的画布。拖尾用 `frame` 的 `trail`（在同一帧里把过去几个时刻叠起来）。这样才能跳着渲、分段渲、回归比对。
- **亮度跟着摊开的面积调。** 点叠得越多越亮：收成一个字时会过曝，摊成满屏噪点时会发灰。每个状态单独给亮度。
- **过渡中途最容易难看。** 路上散开（`scatter`）大了是一团雾；收成一个点时直线走会露出原来的轮廓，用 `swirl` 旋进去。
- 只有一个点的画面太空：给它一圈会呼吸的光，镜头慢慢推。
- 新的构型往 `F` 里加：一个函数，往数组里写每个点的 x、y、z、亮度，位置只由点的随机数和 `t` 决定。

## 五、看片要看的地方

`stills` 至少抽这些时刻，一张张放大看：每一场稳住以后的一帧；每个过渡正中间的一帧；第一句字和最后一句字；炸开后半秒；全片最后一秒。

- 每一场不看字，能不能说出它的规则？说不出，回去改构型，不是加字。
- 过渡中间是一团糊，还是看得出“正在从这个变成那个”？
- 字压在亮的地方读不读得清（`say` 自带一条暗带）；竖版里字和代码有没有进平台遮挡区。
- 静场超过两小节没有任何变化的地方，加一点持续的小动作（自转、信号流动、呼吸）。

## 六、出片

- `"cover_lead": false`：片头不垫封面，从黑场开始。封面图照样用 `build.py cover` 出，单独上传。
- `"crf": 15`：满屏细点的画面很吃码率，默认的压缩会糊成色块。这样渲出来的 `silent.mp4` 是母版，两分钟有六百多兆；`final` 会另压一份码率封顶 12M 的成片（`"final_crf"` 可调，缺省 20）用来上传。
- 竖版：`"platform":"douyin"` 另起一个项目目录，同一份 `scenes.js`（场景里用 `H > W` 分支调构型的宽高和字的位置）。
- 三种语言各出一条，文件名带上语言。
- 片尾写一行“全片由代码逐帧画出，是数学规则的示意，不是物理模拟”。这类画面容易被当成科学可视化，说清楚它是什么。

## 常见错

- 每一场都好看，连起来没有弧：没先写那一句话。
- 换场用剪切或淡入淡出：点换了一批，“同一样东西”就断了。
- 字在解说画面，或者句句都是金句：留三分之二的场次只有画面和一行代码也可以。
- 公式是装饰（满屏滚动的无关数学）：它不是成因就不要出现。
- 把示意说成模拟：星系不是 N 体算出来的，网络没有在学习。片尾说明要写，旁白和字里也不能说过头。
- 点数乘拖尾层数超过五十万：一帧要几百毫秒，整片渲几个小时。
