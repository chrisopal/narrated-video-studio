## 二、brief.json 的其他字段

基本字段（题材、风格、受众、时长、方向、声音）见 `流程.md` 第 1 步的例子。下面是各条线和可选项：

宣传线写 `"mode":"promo"`、`"product":{"kind":"virtual|physical|tool|ai","traits":["特性词"]}`，运行 `build.py look` 看建议后写 `"look":"bold|glass|studio|grid|pop"`、`"packs":["promo"]`（配乐和拍速不写就用这套样子的缺省；合成配乐另有 `drive`、`pulse`、`warm`、`bright` 四种，有鼓有低音，按章节强弱起落）。再加 `"slogan":"一句观众带得走的话"`（检查会看它有没有在片尾留够时间），`bpm` 必写；`"shot_max":4`、`"pace_avg":2.5` 是单个镜头和平均镜头的上限秒数，要改写明理由。

口播线写 `"mode":"talk"`、`"talk":{"file":"footage/口播.mp4","speaker":"出镜人","max_pause":0.7}`（停顿超过几秒就收紧），`"packs":["talk"]`；竖版另写 `"safe":[110,48,290,48]`。

卡点的片子再加 `"bpm":90`（每分钟几拍；写了它，每一句都从拍点开始，合成配乐的重音落在小节线上）、`"meter":4`（一小节几拍）；用自己的音乐时先运行 `python3 ../kit/build.py beats 音乐文件` 量出速度和第一拍，把它给的 `bpm`、`beat_offset` 写进来。

多语言的片子写 `"lang":"zh|en|bi"`（缺省 `zh`）：场景里用 `PACK.gen.say(t, t0, t1, '中文', 'English')` 写字，一份场景改 `lang` 各渲一遍就是三版；别的包里要分语言时读 `PACK.gen.LANG` 或网址参数 `lang`。无旁白短片的配乐用 `"music":"cosmos"`（长音、钟声、小节线上的低鼓，`"music_energy":[每章一个 0–1 的数]` 定起伏）。出片：`"cover_lead":false` 片头不垫封面，`"crf":15` 提高画质（缺省 18，满屏细点的画面要调低）。

可选字段：`"platform":"douyin|channels|xhs|xhs_full|bilibili|youtube"` 发布平台（定画幅和安全区；`xhs_full` 是小红书全屏 9:16）；`"aspect":"9:16|3:4|16:9"` 和 `"safe":[上,右,下,左]` 直接指定；`"packs":["ink","figures","map"]` 要加载的风格包；`"music":"guqin"` 五声拨弦配乐、每章换调（缺省 `keys` 是合成的键盘铺底，中音区，手机喇叭听得见；`pad` 是低沉长音；写成文件路径就用那条音乐，文件要进素材台账）；`"music_gain":3` 配乐整体加减几分贝（用户说听不清或太吵时调它）；`"sfx":false` 不加音效（水墨一类安静的片子）；`"duck":12` 旁白时素材原声压低多少分贝（缺省 12，`false` 不压低）；`"tiers_required":true` 断言台账每条都要填来源层级 `tier`（企业、产业类必开）；`"must_show":["不构成投资建议"]` 片中必须出现的声明（检查要求整句至少清楚显示 2 秒）。

`read_cps` 是屏幕文字的阅读速度：给孩子看 4.5 字/秒，成年观众可到 6。

## 三、通用组件（`kit/components.js`）

- 品牌字：`brand(()=>{ txt('史书留白',…) })` 里画的账号名、口号不算阅读时长、允许放在竖版平台遮挡区；只给品牌字用（kit.js）


| 组件 | 调用 | 用在 |
|---|---|---|
| 基础 | `txt rise pop pill card arrow dash wave glow person photo photoCircle` | 随处 |
| 文字 | `wrap(s,宽,字号)` `para(…)` `numtxt(s,x,y,字号,色,对齐)` | 折行、粗体数字 |
| 人名条 | `lowerThird(t,t0,'姓名','身份',x,y,t1)` | 谁在说话、这是哪里 |
| 年代戳 | `dateStamp(t,t0,'1969','一行说明',x,y)` | 历史、新闻 |
| 时间轴 | `timeline(t,t0,[{tag,label,at}],{y,x0,x1})` | 历程、人生、事件线 |
| 引文 | `quoteCard(t,t0,'原话','出处',x,y,w)` | 必须有出处 |
| 大数字 | `bigNumber(t,t0,{value,unit,label,note,prefix,decimals},x,y,字号)` | 念到 t0 时落定 |
| 柱图 | `barChart(t,t0,[{label,value,hi}],x,y,w,h,{title,unit,source,decimals})` | 一根主角，其余退灰 |
| 折线 | `lineChart(t,t0,[{label,v}],x,y,w,h,{title,unit,dur,marks:[{i,label}],source})` | 线头经过时出标注 |
| 参数表 | `specTable(t,t0,[['项','值']],x,y,w,{title})` | 规格、口径 |
| 流程 | `flowSteps(t,[{label,sub,at}],x,y,w)` | 工序，当前步高亮 |
| 对比 | `compare2(t,t0,{title,lines},{title,lines},{y,h,tR})` | 前后、新旧、两种方案 |
| 标注 | `callout(t,t0,px,py,lx,ly,'名称','说明',色)` | 指着零件、界面、照片讲 |
| 来源 | `sourceTag(t,t0,'来源：…')` | 数字、截图旁边 |
| 荧光笔 | `highlight(t,t0,x,y,w,h)`（写在被划的文字之前） | 截图、引文里正在念的那句 |
| 图章 | `stamp(t,t0,'已核实',x,y)` | 定论、合格 |
| 章节卡 | `chapterCard(t,t0,t1,序号,'标题','一句话')` | 长片分章 |
| 三张卡 | `threeCards(t,id,'标题',[{tag,title,sub,at,subAt,titleAt,icon}])` | 收尾总结，先原因后结论 |
| 视频片段 | `clip('素材id',t,t0,x,y,w,h,{from,speed,sound,credit,fit,kb,fade,t1})` `clipFull(id,t,t0,t1,{…})` `clipSound(id,t,t0,{from,gain,t1,fadeIn,fadeOut})`；转场 `xfade(t,tCut,d,画A,画B)` `dipTo(t,tCut,d,色,画A,画B)` `wipe(t,tCut,d,方向,画A,画B)`（详见 `templates/素材与剪辑.md`） | 真设备、真现场、真界面；fit 铺法 cover/contain/blur，kb 推拉摇，clipSound 做 J/L-cut，原声在旁白下自动压低 |
| 片尾 | `credits(t,t0,[…])` `creditLines()` | 依据、素材署名 |
| 声音 | `sfx('ding',时刻)`：`pop tick whoosh ding rise thud` | 结论落地用 ding，展开用 rise |
